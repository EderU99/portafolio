## 📋 Sobre este proyecto

Portafolio web interactivo desarrollado con **Angular** y **SCSS**, diseñado con una estética moderna *Cyber-Tech* que incluye:
- **Pantalla de Carga (Splash Screen) Animada** con anillos orbitales y revelación de nombre.
- **Efecto Máquina de Escribir (Typewriter)** dinámico en vivo.
- **Terminal Interactiva 3D** con múltiples vistas de perfil (`perfil.ts`, `infra_ti.sh`, `stack.json`).
- **Carrusel en Movimiento** con logotipos oficiales de tecnologías, frameworks, bases de datos y agentes de IA.
- **Animaciones de Scroll (`IntersectionObserver`)** y barras de progreso dinámicas.

## 🛠️ Tecnologías Destacadas en el Portafolio
- **Frontend:** Angular, TypeScript, JavaScript (ES6+), HTML5, CSS3 / SCSS
- **Backend:** .NET Core / ASP.NET, Laravel, PHP, Python
- **Bases de Datos:** MySQL, SQL Server, MongoDB
- **Infraestructura & Soporte TI:** Soporte Técnico Nivel 1 y 2, Microsoft 365 (Exchange, SharePoint), Bitdefender, Redes y Sistemas de Tickets
- **Inteligencia Artificial:** Gemini CLI (Antigravity), Grok Build, ComfyUI (Generación local de video e imagen)
